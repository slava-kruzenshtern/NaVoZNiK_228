CICADA-STYLE 5-KEY GATE
===========================

Files:
- index.html  — first page with five password fields
- next.html   — page shown after successful verification

Default passwords:
1. RAVEN
2. CAESAR
3. ORACLE
4. 3301
5. ASCENSION

To change them:
Open index.html and edit the KEYS array near the bottom.

IMPORTANT:
This is a static HTML/JavaScript gate. The passwords are present in the page source,
so it is suitable for a puzzle/quest, but NOT for protecting real secrets.

For hosting:
Upload index.html and next.html to GitHub Pages, Netlify, Vercel, or any ordinary web host.
